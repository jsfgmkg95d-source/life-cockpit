# Security policy

The current public beta is supported. Keep a backup before installing an update.

Please report suspected vulnerabilities through GitHub's **Security → Report a vulnerability** when available. Do not post a working exploit against other people, credentials or private data in public issues. If private reporting is unavailable, open an issue requesting a private reporting channel without technical exploit details.

The server is intended for local use and binds to loopback. It is not designed to be exposed to the Internet or a shared network. Online AI is optional; enabling it sends the requested report's business summary to the selected supported API.

For ordinary errors, open an issue with the version, Windows version and synthetic reproduction steps. Redact personal paths and project content before attaching logs.
