# 路线图

人生驾驶舱先把“安排今天 → 记录投入 → 回顾积累”做好。下面是方向，不是上线日期承诺。

## 当前 Beta

Windows x64、本地项目与任务、专注计时、桌面小组件、成果记录、回顾、手动备份与恢复，以及可选在线 AI。

## 优先改进

1. **首次使用。** 缩短下载到第一次记录之间的步骤，让示例和个人数据的边界更清楚。
2. **稳定性。** 根据真实试用处理计时中断、退出、更新、备份恢复和不同屏幕尺寸的问题。
3. **回顾的可读性。** 让已知记录、缺失信息、计划与实际更容易区分。
4. **无障碍与文档。** 改进键盘操作、焦点、文本说明和英文资料。

## 需要先讨论

更多平台、同步、多用户、插件与新的 AI 提供商，需要明确需求、数据边界和维护成本。当前不承诺推出。

## 怎样参与

从 [Issues](https://github.com/jsfgmkg95d-source/life-cockpit/issues/new/choose) 描述一个具体场景：你想做什么，在哪一步受阻，现在怎样解决。比起功能清单，一个可以复现的问题或完整使用过程更有帮助。
