## 简介

人生驾驶舱是一个面向独立创作者的 Windows 工作台。

选一项今天要做的事，开始计时，完成后回顾留下的成果。核心功能离线可用，数据保存在本机，无需注册；AI 按需启用。

视频中的项目和数字全部为合成示例，只演示使用方法，不代表效率提升或收入效果。

免费开源 / MIT / Windows x64 Beta / 中文界面

项目与下载：https://github.com/jsfgmkg95d-source/life-cockpit

上手指南：https://github.com/jsfgmkg95d-source/life-cockpit/blob/main/docs/quickstart.md

下载 Release 里的 Windows x64 完整 ZIP，全部解压后打开“人生驾驶舱.exe”。不需要安装 Node.js；页面底部的 Source code 是开发者源码包。

目前暂无云同步和其他平台安装包。欢迎反馈你在首次使用中遇到的具体问题。

## 置顶评论

下载和源码都在：https://github.com/jsfgmkg95d-source/life-cockpit

第一次使用建议只建一个项目、一项任务，跑完“开始计时 → 暂停 → 完成 → 回顾”。关闭窗口后计时会继续；结束工作请在托盘菜单选择“暂停并退出”。

反馈请带上版本和操作步骤。截图记得遮住私人信息，不要上传账本或备份。
