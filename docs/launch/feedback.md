# 首批试用反馈

感谢试用人生驾驶舱。反馈可以发到 [GitHub Issues](https://github.com/jsfgmkg95d-source/life-cockpit/issues/new/choose)，也可以只回答下列与你有关的问题。无需提供账本或私人项目内容。

## 第一次使用后

1. 你觉得这个工具是做什么的？用自己的一句话描述。
2. 你使用的应用版本、Windows 版本是什么？
3. 是否独立完成了下载、打开、创建任务、计时、完成、查看回顾？卡在哪一步？
4. 哪个按钮或词语让你不确定接下来会发生什么？
5. 如果只能先改一处，你希望改哪里？

## 使用七天后

1. 这七天里大约使用了几天？
2. 你最常用哪项功能？哪项几乎不用？
3. 有没有一次回顾帮助你调整了具体安排？请描述发生了什么，也可以回答“没有”。
4. 什么原因会让你继续用，或放弃使用？

如遇错误，请另外附上可复现的操作步骤、预期与实际结果。截图请先遮挡私人信息。维护者引用你的反馈前，会单独确认引用内容与署名方式。
