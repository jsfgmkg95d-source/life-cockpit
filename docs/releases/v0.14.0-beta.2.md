# 人生驾驶舱 Beta 2：每日计划随任务自动调整

新增任务、修改任务分类或移除任务后，计划会自动启用有任务的评分维度，并重新计算分值。无需再手动勾选适用维度、填写不适用原因或凑满分值。

例如，今天只有现金流任务时，这一维度占当天计划评分的 100%；现金流与长期资产都有任务时，分别占 62.5% 与 37.5%。这是计划评分的占比，不代表收入或资产价值。

## 本次修复

- 计划预览与确认使用同一套自动分配规则，新增、跨维度移动和移除任务后即时更新。
- 相对权重可以留空；全部留空时平均分配。已有完整有效的分配保持原样。
- 旧草稿在预览和确认时自动适配。已确认的历史快照不改写，任务身份、完成状态、成果和实际用时继续保留。

数据库版本仍为 9，无需迁移或重新建立账本。任务完成、用时和成果仍是独立记录。详见[规则与验证说明](https://github.com/jsfgmkg95d-source/life-cockpit/blob/main/docs/adaptive-dimensions.md)。

## 下载与更新

下载 `life-cockpit-0.14.0-beta.2-windows-x64.zip`，完整解压后双击“人生驾驶舱.exe”。程序自带运行环境，无需安装 Node.js。

已有 Beta 1 用户：先创建本地备份，在旧版选择“暂停并退出”，再把新版解压到新文件夹并打开。同一 Windows 用户会沿用已保存的账本设置。不要覆盖或移动账本目录。
