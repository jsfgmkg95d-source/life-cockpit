# 人生驾驶舱首个公开 Beta

人生驾驶舱是面向独立创作者的 Windows 时间与项目工作台。安排今天的任务，记录实际投入，再回顾留下的成果。

[项目介绍](https://jsfgmkg95d-source.github.io/life-cockpit/) · [观看 60 秒演示](https://github.com/jsfgmkg95d-source/life-cockpit/releases/download/v0.14.0-beta.1/life-cockpit-demo-60s.mp4)

## 下载与开始

下载 `life-cockpit-0.14.0-beta.1-windows-x64.zip`，完整解压后双击“人生驾驶舱.exe”。程序自带运行环境，无需安装 Node.js，也无需配置 API Key。

首次打开可以建立空白工作台，或体验独立保存的合成示例。先创建一个项目和一项任务，再试一次计时、暂停、完成与回顾。

- [三步上手与备份说明](https://github.com/jsfgmkg95d-source/life-cockpit/blob/main/docs/quickstart.md)
- [数据与隐私](https://github.com/jsfgmkg95d-source/life-cockpit/blob/main/docs/privacy.md)
- [报告问题](https://github.com/jsfgmkg95d-source/life-cockpit/issues/new/choose)

## 本版内容

- 收件箱、今日任务、计划时间安排、任务完成与撤销。
- 原生专注计时、实际用时记录与 Windows 桌面小组件。
- 项目档案、成果记录、历史回顾与积累。
- 手动一致性备份、JSON 导出与核对恢复。
- 核心功能离线可用；OpenAI 报告按需启用。
- 独立的公开版数据目录、原创指南针图标、MIT 开源代码。

任务完成、用时和成果分别保存。计时不会自动完成任务，也不把投入换算成收益或能力。

## 使用前了解

当前为 Windows x64 Beta，主要使用中文界面。尚不提供云同步、自动更新、多人协作或其他系统安装包。Windows 程序未进行商业代码签名；系统可能显示未知发布者提示，请核对下载来源和校验值，不要关闭系统防护。

关闭窗口会收起到托盘并继续计时；完全退出请使用“暂停并退出”。更新前先备份，将新程序解压到新文件夹，退出旧版后再打开新版。

演示截图与视频使用合成数据，未包含作者的日常账本。欢迎反馈第一次使用时哪里难理解、哪里卡住；请不要上传个人数据库、备份或 API Key。
