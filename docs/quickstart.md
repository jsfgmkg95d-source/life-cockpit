# 三步开始使用人生驾驶舱

先用一个项目和一项任务跑完流程。其他设置可以以后再补。

## 1. 下载并打开

打开 [Windows Beta 下载页](https://github.com/jsfgmkg95d-source/life-cockpit/releases/tag/v0.14.0-beta.1)，下载完整的 `life-cockpit-0.14.0-beta.1-windows-x64.zip`。页面底部的 `Source code` 是开发者源码包。

右键 ZIP →“全部解压”，将整个文件夹放到一个固定位置，再双击 **人生驾驶舱.exe**。保留同文件夹中的 `resources` 等配套文件；只移动 EXE 无法运行。

本版面向 Windows x64。普通使用不需要安装 Node.js、注册账号或填写 API Key。若系统提示发布者未验证，先核对文件来自本仓库的 Release，以及随包提供的 SHA-256 校验值，再决定是否运行；请不要关闭系统防护。

## 2. 建立自己的工作台

首次打开后点击“建立我的工作台”，添加一个项目，例如“写一篇文章”。写下一项具体的下一步，例如“列出三个论点”，然后保存。

想先看界面可以点击“体验示例”。示例只用于体验，名称和数字均为虚构，与个人记录分开保存。准备正式记录时，点击顶部“返回我的工作台”，建立自己的项目。

## 3. 做完第一次记录

在“今天”添加一项任务，选择对应项目。点击计时按钮开始工作，结束后暂停保存，再点击“完成”。完成可以撤销。

任务完成不会自动填入产出。如果确实形成了稿件、版本或其他成果，可以另外记录；先只使用任务和计时也可以。

到回顾页查看今天的记录。连续记录几天后，可以按项目检查时间分配和成果，再决定下一周继续什么、调整什么。缺少记录的日期表示未知，不代表当天没有工作。

## 关闭窗口和停止计时

点击窗口右上角的关闭按钮后，应用会留在系统托盘中，正在运行的计时继续。需要结束当天工作时，从“驾驶舱”菜单或托盘菜单选择 **“暂停并退出”**。下次打开会读取原来的本地记录。

如果系统异常关机或进程被强制终止，下次启动后请核对未结束的计时记录。

## 找到、备份和恢复数据

从桌面菜单选择 **“打开账本文件夹”** 可定位当前账本。新账本默认保存在 `%APPDATA%\LifeCockpit\data`，应用文件和账本分开保存；若主动选择已有账本，以菜单打开的位置为准。

在“设置 → 数据与备份”点击“创建本地备份”。把生成的整份备份编号文件夹复制到另一块磁盘，保留 `database.sqlite`、`export.json` 和 `manifest.json` 三个文件。

备份是手动的，不会定时上传。备份不包含 API 密钥或外部链接所指向的稿件、附件；这些文件需要单独保管。

恢复时，把完整备份文件夹放入设置页显示的备份目录，刷新并校验，再点“核对并恢复”。恢复会替换整份当前账本；程序会先创建当前账本的保全备份。请阅读界面显示的时间与范围后再确认。单独的 JSON 文件不能用于覆盖恢复。

## 更新版本

先创建本地备份，然后选择“暂停并退出”。把新版完整 ZIP 解压到一个新的应用文件夹，打开新版 EXE。不要覆盖、移动或删除账本目录。确认旧记录可读后再处理旧程序文件夹。

Beta 暂无自动更新。若遇到数据版本不兼容，请保留原文件并提交错误信息，不要反复覆盖数据库。

## 可选 AI

核心功能无需联网。要使用在线报告，再到设置里配置 OpenAI API 密钥和模型。启用后生成报告会发送记录摘要，具体范围见 [隐私说明](privacy.md)。API 可能产生费用，按服务方规则计费。

## 遇到问题

到 [Issues](https://github.com/jsfgmkg95d-source/life-cockpit/issues/new/choose) 提供版本、Windows 版本、操作步骤和报错。不要上传账本、完整备份或 API Key；截图先遮挡私人内容。
