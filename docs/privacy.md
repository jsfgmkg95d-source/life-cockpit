# 数据与隐私

人生驾驶舱的核心功能在本机运行。桌面程序连接本机回环地址上的服务，项目、任务、计时、成果与报告保存在本地 SQLite 账本中。无需建立在线账号。

## 哪些内容保存在本机

账本包含项目档案、任务及计划版本、实际用时、成果及更正历史、评分、报告、建议采纳记录和相关设置。桌面窗口偏好和运行日志另存于应用设置目录。

“打开账本文件夹”菜单可以定位当前数据。公开版新账本默认位于 `%APPDATA%\LifeCockpit\data`；主动选择已有账本时使用你选择的目录。手动备份包含数据库、JSON 导出和校验清单。它不包含 API 密钥，也不会把外部链接指向的稿件或附件复制进来。

本地保存不等于加密保存。拿到这些文件的人可能读取业务内容，请按私人文件管理账本、导出与备份。

## 可选在线 AI 会发送什么

AI 默认无需配置。核心任务、计时、成果和本地回顾不依赖模型服务。

当前在线报告使用 OpenAI API，接口为 `https://api.openai.com/v1/responses`。主动启用并生成报告时，应用向 OpenAI 发送结构化摘要。内容可能包括：

- 日期、时区、当前项目名称与状态、下一步、目标、里程碑、基线说明。
- 当日计划、任务标题、验收条件、已确认结果与说明。
- 成果标识、摘要、来源文字，以及记录的实际投入。
- 近 7 / 30 日记录统计、此前采纳的建议和可观察到的结果。

“摘要”仍可能包含私人信息。写在项目名、备注或来源字段里的敏感内容也可能进入请求。它不是匿名化保证，也不是只有数字。

应用不会因为生成报告而读取外部链接中的稿件正文。报告与来源快照会保存在本地，方便核对。模型建议需要自行判断，不会替你执行外部操作。

Windows 下通过界面保存的 API Key 使用系统的数据保护能力保存，不写进常规备份。新机器需要重新配置密钥。开发者也可以使用环境变量，因此运行环境的安全性仍由使用者负责。

OpenAI 按其自身 API 隐私、留存和收费条款处理请求。应用请求设置了 `store: false`，但这不等于服务方完全不留存任何日志。ChatGPT 订阅与 API 计费是不同服务。

## 分享和反馈

发布 Issue、截图或日志前，移除项目名称、私人路径、来源链接、密钥及其他不想公开的内容。不要把数据库或完整备份作为普通问题附件上传。

仓库截图与宣传素材使用合成数据。公开源码和发行包不包含作者的个人账本。

## 删除与迁移

删除程序文件夹不一定删除账本。请先用菜单定位数据，导出所需内容，然后退出程序，再自行处理账本与备份。迁移时复制完整备份，通过应用的核对恢复流程恢复；API Key 和外部稿件单独处理。
