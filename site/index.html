从第一件事开始。

第一步

下载并打开

解压完整 ZIP，双击“人生驾驶舱.exe”。无需安装 Node.js 或配置 API Key。

第二步

建立自己的工作台

添加一个项目和今天的第一项任务。也可以先进入独立的示例工作台。

第三步

计时、完成、回顾

开始计时，暂停保存；做完后点完成，再回顾这一次投入。
